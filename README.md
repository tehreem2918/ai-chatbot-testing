# AI Chatbot Testing: Daraz Help Chatbot

**Tester:** Tehreem Fatima
**Date:** 13 Nov 2026
**Method:** 15 realistic customer questions (facts, policy edge cases, unclear requests, false claims, out-of-scope, conflicting wording, angry tone)

## Results
- Correct: 6
- Vague: 9
- Wrong: 0
- Off-brand: 0

Full table with answers and explanations: see `Daraz_Chatbot_Test_Results.xlsx`

## Key findings
- Gave the same canned answer to two different return questions.
- Did not correct the false claim that Cash on Delivery was stopped.
- Correctly rejected a false 30% return fee.
- Handed a legal question to a human agent, and the chat ended with no answer.

## Summary
The bot handled simple questions well but often gave a related but different answer, or only menus and links. It sometimes failed to correct false claims.
